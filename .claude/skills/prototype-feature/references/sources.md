# Sources behind the prototype-feature skill

Condensed from the Head-of-Product knowledge base (Lenny's Newsletter and Podcast archive, `02-prototyping-and-design/`). Each line is a principle the skill relies on and where it came from.

## Whether and when to prototype
- "If you're not prototyping and building to see what you want to build, you're doing it wrong." New projects should "come with prototypes and prompt sets"; changes "in the bowels of Excel" do not need one. Aparna Chennapragada (Microsoft CPO), `aparna-chennapragada.md`.
- Figma leans into prototyping "even before a project gets a green light"; the culture is "see to believe". Mihika Kapoor, `mihika-kapoor.md`.
- PRDs are for features that are "particularly ambiguous" on goals: a one-pager on goals, delightful use cases, failure modes. Cat Wu (Claude Code), `cat-wu.md`.
- "If it's simple, minor, and easily changeable you can likely get away with a short whiteboarding exercise." Katie Dill, `the-pm--design-partnership.md`.
- Non-deterministic features: "you can't mock up all the states, you have to use the actual models underneath." Jenny Wen (Anthropic design), `jenny-wen.md`. Progression from Figma prototypes to prototypes on real data. Tamar Yehoshua, `tamar-yehoshua.md`.
- A strategy doc "wouldn't be complete without wireframes"; words alone produce divergent interpretations. Ravi Mehta, `ravi-mehta.md`.

## Fidelity and time budgets
- Mid-fi is fine for engineers and "a waste of time to push past that"; hi-fi for stakeholders, customers, funding. Discovery mid-fi ~20 min; hi-fi for alignment 20–60 min; user interviews 3–5 days. Set fidelity expectations explicitly before showing. Colin Matthews, `how-to-get-your-entire-team-prototyping-with-ai.md`.
- Scope, fidelity, time horizon and buy-in are dials governed by problem complexity. Katie Dill, `the-pm--design-partnership.md`.
- "You just have to be very, very clear with your team on what phase you're in." Jiaona Zhang, `jiaona-zhang.md`.

## Tools and prompting
- Tool by job: chat artifacts, v0, Bolt, Replit, Lovable, Cursor. Prompting: reflection before code, batch the smallest slice, "start with the data model first", be specific, use checkpoints. `a-guide-to-ai-prototyping-for-product-managers.md`.
- Bolt/Lovable/v0/Replit are "the same bucket"; graduate to Cursor/Claude Code for control. Plan-first "CTO" persona told to "challenge me, I don't want you to be a people pleaser." Zevi Arnovitz, `zevi-arnovitz.md`.
- "Focus on front end functionality, do not include a server or database." PRD-to-prototype prompt, `a-guide-to-ai-prototyping-for-product-managers.md`.
- Component libraries via screenshots, extension, or Figma MCP + Cursor; "baselines and forks". `how-to-get-your-entire-team-prototyping-with-ai.md`.

## Explore several directions
- Coding tools are "super linear, you get super invested in one direction"; Figma remains the place to explore "8 to 10 different ways". Jenny Wen, `jenny-wen.md`.
- Figma product reviews map the "option space" before debating one. `how-figma-builds-product.md`.

## Keep prototype code out of production
- "The code generated by AI prototyping tools is mostly useless to your engineering team" except for documenting specific interactions like animations. `how-to-get-your-entire-team-prototyping-with-ai.md`.
- "You write code that is never going to make it to production so you can just crank it out much faster." Tamar Yehoshua, `tamar-yehoshua.md`.
- PMs should not ship DB migrations; at most contained UI projects handed to a dev. Zevi Arnovitz, `zevi-arnovitz.md`.
- Build things that "don't necessarily work yet" to expose gaps; use what you build daily. Cat Wu, `cat-wu.md`.

## Editing and anti-patterns
- Supply of ideas explodes; without an editor you get "a Frankenstein product". Aparna Chennapragada, `aparna-chennapragada.md`.
- "Almost, but no" is a valid outcome; "the gravitational pull is to mediocrity." Katie Dill, `katie-dill.md`.
- Two lost years of slide-deck perfectionism at Google Meet instead of a prototype. `introducing-the-foundation-sprint-from-the-creators-of-the-design-sprint.md`.
- Shipping early then never iterating "degrades a brand". Jenny Wen, `jenny-wen.md`.
